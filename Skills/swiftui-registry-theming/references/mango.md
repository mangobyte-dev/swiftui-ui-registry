# MANGO design system

MANGO is the worked example of building a brand on the registry: the tokens, the
typography, the strokeless surface step, the motion vocabulary, the preset code
`a74hGF01CVunaG0vzZJG`, and the eight numbered steps for doing the same for your
own brand.
